# Abhishek Kattimani - Portfolio

Vite + React + Tailwind + Framer Motion + Lucide.

    npm install
    npm run dev        # local
    npm run build      # production build -> dist/

Deploy: push to GitHub, import repo on vercel.com (framework: Vite). Free.

## Edit

- Project GitHub links marked `// TODO` -> paste exact repo URLs
- Contact form: set `formEndpoint` (Formspree) in `src/data.js`; empty = opens mail app
